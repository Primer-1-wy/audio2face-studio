STEP 01 / DATASET

先准备一组好的训练样本

音频 + 3D 动画

每段录音都要有对应的面部顶点动画。先保证音画同步，再增加数据量。

♪

原始录音

PCM WAV ≥ 16 kHz / 16 bit。建议每段 3–30 秒，保留自然发音、停顿和表情变化。

◇

同步顶点动画

NPY、PC2 或 Maya MC/XML。固定顶点数量与顺序，稳定头部运动，统一帧率。

≋

独立验证片段

按完整片段留出约 20%。本工作台至少需要 5 段配对样本；验证片段不参与 PCA。

数据目录与制作方法 查看格式
my_actor/
├── audio/
│   ├── shot01_neutral.wav
│   └── shot02_joy.wav
└── cache/skin/
    ├── shot01_neutral.npy
    └── shot02_joy.npy

NPY 形状
[帧数, 顶点数, 3]，float32 / float64

录制表演 → 面部跟踪 / 动捕 → 在 DCC 中清理并稳定头部 → 烘焙统一网格缓存 → 同步裁切音频。

情绪从片段名匹配；未匹配时为 neutral。请在配置中列出实际使用的情绪。

STEP 02–04 / CONFIGURE & RUN

配置这一次训练

01 模型与训练参数
轮数预设

只接受兼容的训练 .pth；模型架构、拓扑、PCA 维度与情绪定义需匹配。ONNX / NPZ 不能作为微调权重。这里是初始化权重，不是恢复优化器状态。

02 数据来源
NVIDIA Claire 官方样例

从 NVIDIA Hugging Face 数据集下载，包含中文、英文与多种情绪。第一次运行需要网络和磁盘空间。

查看数据集与使用条款 ↗

包含 neutral；情绪名需与片段名一致。自定义数据需要先复制到训练机；此页面的本地目录检查不会自动上传。

03 GPU 训练机

Linux / WSL2，NVIDIA GPU ≥ 6 GB，Docker + NVIDIA Container Toolkit，Python 3、Git 和 Git LFS。6 GB 是官方最低要求，实际显存取决于模型和数据。

使用本机现有 SSH 密钥 / agent 和 known_hosts。请先在终端完成一次可信 SSH 连接；这里不接收密码或私钥。
