有可用角色后的最短操作
1. 打开本目录的 .uproject，在 UE 中创建/导入并完成装配一个 MetaHuman；也可以在已有 MetaHuman 工程启用 Python Editor Script Plugin、Sequencer Scripting、Control Rig 后重启。
2. 将已装配角色放入关卡并保存关卡。在 World Outliner 仅选中该角色。
3. 选择 Tools → Execute Python Script，运行本目录 import_selected_metahuman.py。脚本使用与它同级目录的 ../demo-data/emotions-56s，无需改绝对路径。
4. 脚本创建 /Game/A2FDemo/A2F_Playback（重名则自动追加编号），30 fps，第 0–1679 帧动画；播放范围结束值 1680；音频从第 0 帧开始。
5. 查看新生成的 last_import_report.json。曲线回读比较通过不等同于视觉通过：仍需播放 Sequencer 并检查嘴唇、牙齿、舌头和左右控制方向。如果 status=failed / imported_needs_curve_review，保留报告和 UE Output Log 以便继续调整。
6. 保存包含角色的关卡。脚本只保存新序列及新音频资产，不自动改存已有关卡。

脚本使用 UE 自带 MetaHuman Controls Mapping 预设；不需要 NVIDIA ACE Unreal 插件，因为这次是离线动画回放。
不能将 face.fbx 当作角色网格或普通骨骼动画导入。ZIP 中没有角色头模、材质或 DNA；最小缺少项是一个已经装配并可在 UE 播放的 MetaHuman。

手动导入备用路径
创建 Level Sequence，设置 30 fps，加入 MetaHuman 角色；在 Face / Face_ControlBoard_CtrlRig 轨道选择 Import Control Rig FBX，使用 MetaHuman Controls Mapping，导入 face.fbx 全部控制器；添加 audio.wav 到音频轨道，第 0 帧开始，播放范围 0–1680。
