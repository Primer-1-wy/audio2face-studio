FROM DATA TO TRAINING

从配对数据，到模型验证。

完整工作台源码已收录在仓库，真实训练在你的 NVIDIA GPU 机器上运行。

01 · 准备配对数据

每个 shot 配对 WAV 语音与逐帧网格动画，确认采样率、帧率、时间同步、角色拓扑和顶点顺序。推理结果可用于回放检查，不能直接当作真人采集的真实训练标注。

02 · 检查并划分数据

按完整 shot 划分训练集与验证集，避免相邻帧泄漏。PCA 等预处理只拟合训练数据。先用少量数据检查读取、缓存和训练流程，再扩大数据规模。

03 · 配置训练

本地工作台支持 Diffusion 与 Regression 路线、运行包导出、SSH 环境检查及 Docker 执行。需要 Linux / WSL2、NVIDIA GPU、Docker 与 NVIDIA Container Toolkit。没有 GPU 时可以完成准备和配置，但无法在网页托管环境中训练。

04 · 导出与验证

保留权重、日志、部署模型和验证动画，使用留出语音评估口型同步、唇部闭合、表情强度及时间平滑。训练质量需要真实 GPU 运行验证，短程流程测试不能代替质量验收。
